# Runbook

> **Status: stub.** Grows by one entry each time something breaks. Never needs to be polished.

## Purpose

Every failure mode actually hit, with the fix, written while the knowledge is fresh.

## What this locks in

Nothing — but it is the difference between a bad evening and a bad week.

## Skeleton

- **The nonce rotated or the endpoint moved** — where to look, what to change.
- **Extraction failing on a document class** — how to isolate and re-run just that set.
- **Backfill wave procedure**, including how to resume a partial one.
- **Restore from bulk data** — practise once, before it is needed.
