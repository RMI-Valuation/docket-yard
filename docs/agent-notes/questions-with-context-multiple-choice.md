When a decision belongs to Cameron, ask it as multiple-choice questions (AskUserQuestion),
each with the context needed to decide inside the question itself — what holds today, what
changes, the trade-off per option — and a recommended option first. Not a prose list of
"decisions for you" at the end of a reply.

**Why:** 2026-09-16, deciding whether the MCP server may serve page text: he asked for the
questions again "with enough context for me to make an informed decision with multiple
choice answers", then answered all four in one pass.

**How to apply:** any operator decision (ADR addenda, policy, scope); keep each option's
description to its consequence. See [[adr-acceptance-is-camerons]].
