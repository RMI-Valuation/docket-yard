Coverage and limitations

Every number on this page is measured from the record as it stands, not typed. Last checked {{ cov.last_checked | fmt_when }}.

What is watched

{{ site_name }} asks the Board's record search for new filings and decisions every thirty minutes, across every docket, and has done so continuously since {{ cov.forward_since | fmt_when }}. Environmental comments joined that watch later, and the date above measures the filings and decisions captures only. An entry the Board posts is usually on its sheet within the hour. The record has {{ cov.filings | plural('filing') }}, {{ cov.decisions | plural('decision') }} and {{ cov.comments | plural('environmental comment') }}, and holds {{ cov.documents | plural('document') }} — the Board's own files, kept by their content hash so a replaced file is noticed{% if cov.attachments_unfetched %}; {{ cov.attachments_unfetched | plural('file') }} listed by the Board have not yet been fetched{% endif %}.

The record spans entries the Board dated from {{ cov.record_from | fmt_date }} to {{ cov.record_to | fmt_date }} — what the watch has caught since it began, plus the dated waves described below. Those are the Board's dates, quoted; the watch's own start is the timestamp above.

The docket registry

The registry of proceedings — {{ '{:,}'.format(cov.dockets) }} dockets — was walked in full from the Board's dockets table{% if cov.registry_walked_at %} on {{ cov.registry_walked_at | fmt_date }}{% endif %}, one prefix at a time. Six prefixes the Board's search offers return nothing ({{ cov.empty_prefixes | join(', ') }}); they are listed so that their absence here is not mistaken for a gap.

{#- The walk happens once; the watch has been topping the registry up ever since, and a page that mentioned only the walk was a year out of date the moment a new proceeding opened. Every bound below is read from the constants that enforce it, so the sentence cannot drift from what the poller does (deferred, the caption-refresh review). -#}

That walk is not repeated. Since it, the watch fills in what it misses: each pass asks the Board's dockets table about proceedings that hold records but no caption — at most {{ caption_lookups }} a pass, only those opened in the last {{ caption_window_days }} days, and no more than {{ caption_attempts }} times each, after which the silence is reported rather than asked about again. One row per request, so a proceeding that opened after the walk gains its caption without the registry being walked a second time.
