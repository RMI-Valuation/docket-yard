The record for programs

Everything a page shows is also data at the same address. There are no keys, no accounts and no rate limits; there is a licence, a stability promise and a request to be reasonable. The whole record in one file is on the data page.

Licence

The raw index — every docket, filing, decision, date and document hash, with its provenance — is dedicated to the public domain under CC0 1.0; every JSON response says so in its licence field. The Board's own files are United States government records. The enriched layer (the party module: who filed for whom, resolved to entities) is held out of the JSON and the snapshot until its licence is reviewed; the held field says so on every response. The code that serves all of this is AGPL.

What is stable

  • Addresses are permanent. A docket, filing, decision, party or document address, once served, answers forever — the same record, or a 301 to where it now lives (never a 404 for something that existed). This is a written commitment, not a habit: ADR 0013.
  • Shapes are versioned. Every JSON response carries shape_version (now {{ shape_version }}). It is raised — and announced on the data page — when a field changes name or meaning. New fields may appear without a bump; read by name, not by position.
  • Releases are dated. The software is released as vYYYY.MM.N; this response came from {{ version }}. Nothing about a release is a promise beyond the two lines above.
  • Blanks are blanks. A date is the one the Board printed, in ISO form beside the printed form; nothing is computed from context. Nothing here says what any party's position is.

What is asked of a client

  • Send a User-Agent that names your tool and a way to reach you.
  • Honour Cache-Control and ETag: pages are good for {{ page_cache // 60 }} minutes, JSON for {{ json_cache // 60 }}, a document for {{ document_cache // 86400 }} days; a matching If-None-Match is a 304 and costs nothing.
  • For anything that walks the whole record, take the nightly snapshot instead of a hundred thousand requests. For what changed, take a feed.
  • Reading is anonymous by design (privacy): no cookie is set, no address is logged, only counts by kind of page are kept. There is nothing to sign up for and nothing to authenticate.
  • Quote the caveats with the data. What this record covers and when it began is on the coverage page; how it is made is in the methodology. Every record links the Board's own file, which remains the authority.
